Você está diante do **SANGUE-SUGA**, um empacotador de repositórios feito para arrancar o código de dentro de um projeto e entregar tudo mastigado uma IA ;)

**TENHA MAIS RESPEITO.**

Ele percorre o repositório, encontra os arquivos de código, ignora binários e lixo conhecido, segue links simbólicos, respeita o Git quando possível, identifica arquivos duplicados por SHA-256 e organiza tudo em partes limitadas por um orçamento aproximado de tokens.

No modo compacto, remove comentários reconhecidos de maneira **conservadora**, sem sair passando a foice no código igual um parser bêbado. Quando encontra sintaxe potencialmente perigosa ou ambígua, preserva o conteúdo original.

Cada parte possui seu próprio orçamento e margem de segurança, porque **100.000 tokens declarados não significam necessariamente 100.000 tokens reais em qualquer tokenizer existente**. Aqui a estimativa é local, determinística e baseada em caracteres.

### O que o bicho faz

- Descobre arquivos de código automaticamente
- Trabalha com Git ou `find`
- Segue links simbólicos, inclusive para destinos externos
- Exclui binários e diretórios inúteis
- Remove comentários no modo compacto
- Preserva conteúdo quando a transformação não é segura
- Detecta duplicatas exatas por SHA-256
- Fragmenta arquivos gigantes sem simplesmente jogá-los fora
- Divide o repositório em partes
- Trabalha com orçamento de tokens configurável
- Gera relatório de arquivos, duplicatas, falhas e exclusões

É **pegar um repositório inteiro e transformar aquela floresta de arquivos em um artefato textual organizado, rastreável e adequado para processamento por contexto limitado**.
